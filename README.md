# Consciously Dreaming

An Astro starter for the writing and visual work of Consciously Dreaming.

## Run locally

Install Node.js, then run `npm install` and `npm run dev`. Open the local URL printed by Astro. Run `npm run build` to produce the static site in `dist/`.

## Where things go

- `src/pages/`: URLs and page content. Folder names become URL segments.
- `src/layouts/`: shared HTML shell.
- `src/components/`: repeatable parts such as navigation and footer.
- `src/styles/`: CSS split by purpose, like the PEAK plugin.
- `src/scripts/`: browser behavior.
- `src/assets/`: images Astro will process; `public/`: files copied unchanged.

The writing category pages are placeholders. Add individual pieces when their content is ready. The Origin dropdown contains About and Contact.
